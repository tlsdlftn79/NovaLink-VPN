# NovaLink VPN

**NovaLink VPN**은 Windows 환경에서 가상 사설 네트워크(VPN)를 구성하고, 서로 다른 네트워크에 있는 PC를 하나의 가상 LAN처럼 연결하는 것을 목표로 개발 중인 **C++20 기반 네트워킹 프로젝트**입니다.

개인 간 원격 연결, 가상 네트워크 관리, 그리고 향후 **스타크래프트 등 LAN 기반 게임 연결**을 주요 활용 시나리오로 삼고 있습니다.

> [!IMPORTANT]
> **개발 중인 소프트웨어입니다.** 아래 기능의 구현 여부와 실제 인터넷 환경에서의 작동 검증은 서로 다릅니다. 현재 공개된 개발 단계만으로 안정적인 VPN, NAT 우회 또는 암호화 보안을 보장하지 않습니다. 중요한 업무망이나 민감한 통신에 사용하기 전에는 별도 보안·호환성 검증이 필요합니다.

## 프로젝트 목표

- 사용자가 가상 네트워크를 만들고 다른 사용자가 참가할 수 있는 연결 경험 제공
- 인터넷을 통한 P2P 통신 및 NAT 환경 대응
- 직접 연결이 어려운 경우 Relay(중계) 서버를 통한 연결 지원
- VPN 터널과 가상 네트워크 어댑터 연동
- 서버·클라이언트·참가자·연결 품질을 확인할 수 있는 Windows GUI
- 스타크래프트 등 LAN 탐색 및 UDP 통신을 활용하는 게임 지원
- 운영 중인 자동 업데이트 서비스를 활용한 버전 관리 및 배포 편의성 강화
- 보안성, 안정성 및 시스템 자원 사용량을 검증한 Windows 설치판 제공

## 자동 업데이트 서비스

**NovaLink VPN은 자동 업데이트 서비스를 사용 중입니다.** 이 항목은 프로젝트 운영에 대한 안내이며, 현재 소스만으로 모든 클라이언트에서 자동 업데이트가 정상 작동한다고 검증한 것은 아닙니다.

자동 업데이트를 운영·배포할 때 권장하는 절차는 다음과 같습니다.

1. 클라이언트가 업데이트 서버에서 최신 버전 정보를 조회합니다.
2. 설치된 버전과 서버의 배포 버전을 비교합니다.
3. 새 버전이 있으면 HTTPS를 통해 업데이트 파일을 내려받습니다.
4. 배포 파일의 서명 또는 신뢰할 수 있는 해시를 검증합니다.
5. 프로그램 종료 및 파일 교체 후 재시작하고, 실패 시 복구합니다.

> 위 절차는 **권장 설계**입니다. 실제 구현 여부와 서버 프로토콜은 소스·설정 확인 후 명시해야 합니다. 업데이트 서버 URL, 공개 API, 업데이트 파일 형식, 업데이트 확인 주기 등 확인되지 않은 값은 임의로 기재하지 않았습니다.

### 자동 업데이트 검증 항목

- 최신 버전 조회와 버전 비교가 정상 작동하는지
- 서버 응답 불가·타임아웃 시 기존 설치본이 안전하게 실행되는지
- 배포 파일 서명/해시 검사와 HTTPS 인증서 검증을 수행하는지
- 업데이트 적용 중 프로그램·서비스 종료 및 재시작이 정상적인지
- 다운로드 실패·디스크 공간 부족·업데이트 중단 시 롤백 또는 복구되는지
- 기존 설정과 네트워크 연결 정보가 보존되는지

## 개발 환경

필요한 도구:

1. **Windows 10 또는 Windows 11 (64비트)**
2. **Visual Studio 2022** 또는 Visual Studio 2022 Build Tools
   - Desktop development with C++ / MSVC 툴체인
   - Windows SDK
3. **CMake 3.23.x** (개발 기준: 3.23.5)
4. 가상 네트워크 터널 기능을 시험하는 경우 해당 빌드에서 요구하는 **Wintun 구성요소** 및 관리자 권한

명령 프롬프트에서 버전을 확인합니다.

```bat
cmake --version
```

```bat
where cmake
```

## 빌드 방법

프로젝트 소스를 내려받거나 압축 해제한 후, **`NovaLink.cmd` 파일이 있는 루트 디렉터리**에서 실행합니다.

```bat
cd C:\path\to\NovaLink
NovaLink.cmd build
```

개발 버전에 따라 제공되는 명령이 다를 수 있습니다. **v0.4.x 계열 개발 단계에서 사용한 명령 구성**은 다음과 같습니다.

```bat
NovaLink.cmd build
NovaLink.cmd verify
NovaLink.cmd menu
```

| 명령 | 용도 |
| --- | --- |
| `build` | Windows 빌드 구성 및 컴파일 |
| `verify` | 해당 개발판에서 제공하는 검증 절차 실행 |
| `menu` | 개발용 통합 명령 메뉴 실행 |

이전 **v0.2.0** 소스에서는 다음 명령 형식을 사용했습니다.

```text
NovaLink.cmd build | test | server | client | tunnel
```

현재 소스에 없는 명령은 실행할 수 없으므로, **실제로 포함된 `NovaLink.cmd`의 도움말을 우선** 확인해 주세요.

### GUI 실행

GUI가 포함된 v0.4.x 개발 소스에서 예상하는 Release 빌드 산출물 예시는 다음과 같습니다.

```bat
build-win64\Release\NovaLink.exe
```

실제 EXE 이름이나 출력 경로는 CMake 설정 및 구성별로 달라질 수 있습니다. 빌드 로그에 표시된 실행 파일 경로를 확인하세요.

### CMake 직접 빌드 (대체 방법)

명령 스크립트가 없는 소스 또는 빌드 문제를 진단할 때 사용할 수 있는 일반적인 Visual Studio 2022 빌드 예시입니다.

```bat
cmake -S . -B build-win64 -G "Visual Studio 17 2022" -A x64
cmake --build build-win64 --config Release
```

> 소스의 `CMakeLists.txt`에 정의된 옵션 및 외부 라이브러리 요구사항에 따라 추가 설정이 필요할 수 있습니다.

## 사용 흐름 (개발 목표)

1. NovaLink 서버 또는 제어 서비스를 실행합니다.
2. GUI에서 가상 네트워크를 생성하거나 기존 네트워크에 참가합니다.
3. 참가자 간 인증과 연결 협상을 수행합니다.
4. 가능한 경우 P2P 직접 연결을 사용하고, 불가능한 경우 Relay 경로로 전환합니다.
5. 가상 어댑터·터널·라우팅 설정을 통해 연결된 PC끼리 통신합니다.
6. 네트워크 상태와 송수신 정보를 확인하고 연결을 종료합니다.

**위 과정은 최종 사용 경험을 설명한 것이며 현재 모든 단계가 자동으로 동작한다고 보장하지 않습니다.**

## 연결 구조 (설계 개념)

```text
               +---------------------------+
               |  NovaLink 제어/중계 서버  |
               | 인증 · 세션 · Relay(예정) |
               +-------------+-------------+
                             |
              연결 협상 / 직접 연결 실패 시 중계
                             |
        +--------------------+--------------------+
        |                                         |
+-------v---------+                     +---------v-------+
| PC A / NovaLink | <--- P2P 또는 Relay ---> | NovaLink / PC B |
| GUI + VPN 터널  |                     | VPN 터널 + GUI  |
+-----------------+                     +-----------------+
```

가상 네트워크 어댑터와 터널은 Wintun 등 별도 구성요소를 이용할 수 있으며, 인터넷 P2P/NAT 우회/Relay 선택 로직은 단계적으로 검증합니다.

## 문제 해결

**`cmake` 명령을 찾지 못하는 경우**

CMake 3.23.x 설치 경로를 확인하고 PATH를 설정한 뒤 새 명령 프롬프트를 열어 `cmake --version`을 실행하세요.

**MSVC 또는 Windows SDK를 찾지 못하는 경우**

Visual Studio Installer에서 C++ 데스크톱 개발 구성요소와 Windows SDK가 설치되어 있는지 확인하세요.

**터널이나 가상 어댑터가 생성되지 않는 경우**

Wintun 구성요소, 실행 권한, Windows 방화벽 및 가상 어댑터 상태를 확인하세요. 관리자 권한이 필요할 수 있습니다.

**인터넷 P2P 연결이 실패하는 경우**

NAT·방화벽 환경에 따라 직접 연결이 제한될 수 있습니다. Relay 전환 기능이 없는 개발판에서는 연결에 실패할 수 있습니다.

**자동 업데이트 확인 또는 설치에 실패하는 경우**

업데이트 서버 연결, TLS 인증서, 버전 정보 응답, 업데이트 파일 무결성 및 파일 쓰기 권한을 확인하세요. 업데이트가 실패해도 기존 설치본을 보존하도록 구성하는 것이 좋습니다.

**LAN 게임이 검색되지 않는 경우**

VPN 연결 여부만으로 게임 검색이 보장되지는 않습니다. 게임 버전, UDP 전달, 브로드캐스트/검색 방식 및 방화벽 설정을 함께 확인해야 합니다.

NovaLink VPN은 현재 개발·시험 중인 프로젝트입니다.

- 실서비스용 보안 VPN으로 간주하지 마세요.
- 테스트용 네트워크와 중요 업무망을 분리하세요.
- 암호화 구현이 존재하더라도 키 관리·상대 인증·프로토콜 검증 없이는 통신 보안을 보장할 수 없습니다.
- 테스트 후 방화벽 예외, 가상 어댑터 및 라우팅 설정을 확인하세요.
- 자동 업데이트 배포 파일은 HTTPS와 무결성/서명 검증을 함께 적용하는 것을 권장합니다.
- 확인되지 않은 제3자의 서버에는 민감한 데이터를 전송하지 마세요.
